// configurar

Mostrar u ocultar proyectos

Los cambios se guardan en data.json del repo y se propagan a la intranet en ~30 s.

¿Cómo se autoriza el guardado?

Al guardar por primera vez te pedirá un GitHub Personal Access Token (fine-grained).

  1. Ve a Settings → Developer settings → Fine-grained tokens
  2. Repository access: Only select repositories → elige puntozero-intranet
  3. Permissions → Repository permissions → Contents: Read and write
  4. Genera y copia. Se guarda en tu navegador (localStorage), nunca sale del cliente excepto a github.com.
